# Minesweeper-CPP-Project
A Minesweeper game developed in C++ using Raylib.

1. Project Overview:
   This project is developed as part of the Programming Fundamentals (PF) Course.

2. Project Purpose:
   The main purpose of this project is to demonstrate programming concepts using C++. The project uses Raylib for graphics, rendering, and other multimedia functionalities.
