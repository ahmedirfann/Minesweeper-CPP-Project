# Minesweeper-CPP-Project
A Minesweeper game developed in C++ using Raylib.

1. Project Overview:
   This project is developed as part of the Programming Fundamentals (PF) Course.

2. Project Purpose:
   The main purpose of this project is to demonstrate programming concepts using C++. The project uses Raylib for graphics, rendering, and other multimedia functionalities.

3. Prerequisites:
   1. IDE: Visual Studio 2026/2022
   2. C++ compiler
   3. Raylib version 6.2.0 64-bit version
   4. All assets (images used in the game including bomb.png and flag.png)

4. Installation and Setup
   1. Download or clone the project repository from GitHub.
   2. Extract the project files.
   3. Make sure the required libraries are available in the "lib" directory.
   4. Configure the compiler and library paths if required.
   5. Ensure all assets are present in the correct directories.
  
5. How to Compile and Run
   1. Open the project directory in the terminal.
   2. Compile the project using the provided Makefile:
      make
   Run the generated executable:
      ./main
   For Windows, run:
      main.exe

6. Configuration
- Make sure the compiler is properly configured.
- Set the correct include and library paths.
- Ensure all required DLL files are accessible when running on Windows.
- Keep the assets directory in its expected location.

7. Troubleshooting
   1. Issue: Library not found
      Check whether the library is present and its include and library paths are correctly configured.
   2. Issue: Missing DLL files
      Ensure the required DLL files are available alongside the executable or in the system PATH.
   3. Issue: Assets not loading
      Check that the assets directory exists and that file paths are correct.
   4. Issue: Compilation errors
      Verify the compiler version and compatibility with the installed libraries.
